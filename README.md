# EGMERS — Buyer-Facing Acquisition Showcase

Public GitHub Pages presentation for **EGMERS — Evidence-Grounded Multi-Expert Reasoning**.

## Purpose

This repository is a public commercial presentation layer for potential acquirers, strategic investors, R&D organizations and technology evaluators.

It is designed to explain what EGMERS is, the problem it addresses, what has actually been developed, why it may matter strategically, which organizations may find it relevant, what future development paths may exist, and where public information ends and confidential diligence begins.

It is not technical documentation for the underlying proprietary software.

## Public maturity statement

**Developed software.**

The website deliberately distinguishes current capability, internal evidence posture and future potential. It does not claim general AI superiority or human-expert superiority as an established result.

## Public / confidential boundary

The public presentation excludes reconstructive implementation information. Confidential technical substantiation may be reviewed under appropriate due-diligence conditions and is not stored in this public website repository.

## Website architecture

Static presentation only: HTML, CSS, original local SVG assets, no application backend, no database, no authentication, no payment processing, no analytics, no advertising, no third-party scripts, no external fonts and no forms.

## Visual direction

The site interprets the TheArchitectMax visual language through chiaroscuro, tenebrism and sfumato, using near-black foundations, localized amber evidence light, cool blue reasoning atmosphere, serif conceptual headings and restrained editorial structure.

No external images are used. See [`IMAGE_CREDITS.md`](IMAGE_CREDITS.md).
